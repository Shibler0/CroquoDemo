# CroquoDemo
Croquo est une application mobile crossplatform de mutualisation de livraison de repas

## Stack

Kotlin, Compose Multiplatform, Ktor, PostgreSQL, PostGIS, Docker, Stripe.

## Fonctionnalités principales

JWT, OTP, Google/Apple Sign-In, création de commandes, notifications, paiement Stripe, tri géographique des commandes avec PostGIS.

## Architecture

  - Mobile (MVVM)
